# Platform icons

Apple and Android SVG marks are vendored unchanged from Simple Icons 16.0.0:

- https://github.com/simple-icons/simple-icons/blob/16.0.0/icons/apple.svg
- https://github.com/simple-icons/simple-icons/blob/16.0.0/icons/android.svg

Source project: https://simpleicons.org/
Project license: CC0 1.0 Universal; see PlatformIcons-LICENSE.md.
Brand marks remain the property of their respective owners. These assets identify
connected device platforms in the device list.

Xcode renders the original SVG paths as template images to match light/dark appearance.
